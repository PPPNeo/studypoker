# ♠️ GTO Playbook KR (포커 이론 인터랙티브 학습 플랫폼)

GTO Wizard의 방대한 영문 고급 이론 아티클들을 한국 포커 플레이어들이 가장 **쉽고, 재밌게, 인터랙티브하게** 학습하고 체화할 수 있도록 설계된 웹 기반 게이미피케이션 학습 플랫폼입니다.

---

## 🌟 핵심 기능

1. **📚 스마트 아티클 리더 (Smart Reader)**
   - **한국어 로컬라이징**: 국내 포커 커뮤니티에서 통용되는 자연스러운 용어로 완벽 번역 및 재가공.
   - **3분 핵심 요약 (TL;DR 카드)**: 본문을 읽기 전 3가지 핵심 결론을 카드뉴스로 미리 파악.
   - **인터랙티브 용어 팝오버**: `[MDF]`, `[Polarized]`, `[EQR]`, `[Blocker]` 등 전문 용어에 마우스를 올리면 쉬운 비유와 공식 팝업 제공.
   - **아티클 연계 체크업 퀴즈**: 각 아티클 학습 후 즉시 실전 적용 문제를 풀고 +50 XP 획득.

2. **🎯 GTO 스팟 트레이너 (Spot Quiz Simulator)**
   - 리얼한 포커 테이블 펠트 및 플랍/턴/리버 커뮤니티 카드, 히어로 핸드 그래픽 렌더링.
   - 다양한 스트리트 상황(A-high 3벳 팟 C-bet, 리버 블러프 선정, 웻 보드 프로텍션, ICM 버블 등)에서 액션 선택.
   - GTO 솔루션 빈도와 EV 차이, 개념적 이유('Why')를 즉각 피드백.

3. **📊 13x13 GTO 레인지 매트릭스 (Range Explorer)**
   - 169개 전체 핸드(AA ~ 72o)의 포켓 페어, 수티드, 오프수트 콤보 그리드 제공.
   - BTN 오픈 2.5bb, BB 디펜드 vs BTN 등 프리셋 전환.
   - 핸드에 마우스를 올리면 조합 수(combos), 권장 액션, 빈도(%)를 실시간 인스펙션.

4. **🗺️ RPG 스킬 트리 & 로드맵 (Progression Roadmap)**
   - `Lv.1 피쉬 탈출` ➔ `Lv.2 펍 레귤러` ➔ `Lv.3 온라인 그라인더` ➔ `Lv.4 GTO 마스터`로 이어지는 4단계 성장 시스템.
   - 퀴즈 정답 및 아티클 완독 시 XP 획득, 레벨업 및 업적 뱃지 해금.

5. **🤖 AI 포커 코치 (AI Poker Coach)**
   - 아티클이나 실전에서 헷갈리는 스팟을 자유롭게 질문하고 GTO 기반 맞춤 답변을 실시간 제공.

6. **🕷️ GTO Wizard 블로그 크롤러 & 파서 탑재 (`scripts/scraper.py`)**
   - Ghost CMS 기반의 GTO Wizard 블로그 아티클 및 사이트맵을 실시간으로 크롤링하고 구조화할 수 있는 확장 파이프라인.

## 🚀 실행 방법

### 1. 가상환경 또는 로컬 실행

```bash
python app.py
```
